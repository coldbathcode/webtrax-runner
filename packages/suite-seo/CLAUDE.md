# @webtrax/suite-seo

SEO basics (C05.4): title (missing, > 70 characters, duplicated across pages), meta description, h1 (missing, several), noindex (meta robots, meta webtraxbot, X-Robots-Tag) and `<html lang>`. Only pages that returned 200. Rules in `SEO_RULES`. Duplicate titles are found in `onSite` from the page records, one finding per page with the title as evidence key. The full technical SEO suite is C06.3.

**C06.3, first slice:** `seo.meta_description.duplicate` (site level, by canonical like titles), `seo.canonical.multiple` (tags and the `Link` header disagree), `seo.canonical.cross_domain` (another host, `www.` ignored; quiet on local and deploy-preview hosts, `previewOrLocalHost`, because those name production on purpose: docs-check and PR previews found this), `seo.social.og_missing` (all three of og:title/description/image missing, not on noindex pages), `seo.headings.skipped_level` (first skip only), `seo.links.nofollow_internal`, `seo.hreflang.invalid` (bad codes or no self link per page, key `page`; missing return links between crawled pages, key `return`), `seo.robots.blocks_sitemap_url` (sitemap edges disallowed for Googlebot, robots.txt read with `ctx.text`). Per-crawl state in a `WeakMap` keyed by the crawl's `SuiteCtx`.
